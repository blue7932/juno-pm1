RocketShip PMs need this handled: Juno gathers all the customer feedback from the past two weeks. Juno does this inside limits a human set on purpose, and defends every call it makes.

## 01 Context · Data Requirements

**Required sources, and exclusions**

ZenDesk tickets and call transcripts, slack conversations, interview transcripts from Zoom, stakeholders' Asana boards, Reddit boards and Facebook groups, Clarity video recordings and transcripts

**How fresh must it be**

Changes and additions in sources immediately become changes and additions in the weekly report. If a source is unreachable, flag it for a human with instructions for manually retrieving files and feeding them to the project.

## 02 Tools · System Capabilities

**The verb list**

It can take customer feedback and suggestions from all of these places, distill them down to distinct categories, count the instances that each category appeared, find supporting videos in Clarity, and draft a brief that contains context, customer segment, problem, proposed solutions, technical specs, prototypes, and estimated impact. With permission, it can draft Asana tickets.

**Deliberate omissions**

No codebase access.

## 03 Loop · AI Costs & Latency

**Turn ceiling and escalation**

It can try to access each feedback source three times if there are technical difficulties, and then it must flag the issue to the human handler.

**Latency and cost target**

Answers back within 15 seconds almost every time, and cost per task stays predictable.

## 04 Memory · Data Requirements

**What persists, at what scope**

Context carries on from one session to the next, but only keep the last six months in memory.

**Expiry and write rules**

Keep the past six months in memory, but favor the past six weeks. Human corrections should take precedence over stored model outputs.

## 05 Permissions · AI Risks & Mitigations

**The permission tier**

| Side-effect class | Tier |
|---|---|
| read | auto |
| draft | auto |
| write | confirm |
| send | blocked |

**Justification**

It can access all the context sources without asking and draft the brief without asking, unless it needs a specific question answered.

## 06 Verification · AI Testing & Measurement

**The check before output ships**

Check all numbers justifying the breadth of the problem against all sources where they appear.

**Failure behaviour**

If there are conflicts in the underlying analytics and business projections, flag them for a human to unravel.
